# ai-usage (Claude Code 플러그인)

**Claude** 의 남은 사용량(5시간 · 주간)을 Claude Code 상태줄에 `Claude 🟢5h 71% 🟢주 93%` 처럼 보여주고,
`/ai-usage` 명령으로 갱신 시각까지 자세히 보여줍니다.

- 1분마다 갱신하되 서버 조회는 3분 간격으로만 보내 요청 제한(429)을 피합니다.
- 오류가 나면 마지막 정상값을 ` ~` 표시와 함께 유지합니다.
- 이 PC 에 로그인된 Claude Code 의 로그인 정보를 읽기만 합니다(저장·갱신·외부 전송 없음, Anthropic 공식 서버로만 요청). Mac 은 키체인에서 읽습니다.
- Claude Code 가 켜져 있을 때만 동작합니다. Codex·Gemini 사용량과 작업표시줄·상태표시줄에 항상 떠 있는 표시는 저장소의 위젯 앱(Windows exe / Mac 앱)을 쓰세요.
- 비공식 API 를 사용하므로 서비스 쪽 변경으로 동작이 바뀔 수 있습니다.
